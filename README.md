# azd-risk-based-ca

Staging area for an Azure Developer CLI solution that deploys risk-based Microsoft Entra Conditional Access policies with risk notifications for users and administrators.

## Planned scope

- User-risk and sign-in-risk Conditional Access policies.
- Report-only, pilot, and production deployment modes.
- Notifications for affected users and administrators.
- Emergency-access safeguards, policy validation, staged rollout, and rollback support.
